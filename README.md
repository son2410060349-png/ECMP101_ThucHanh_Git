## Mục tiêu
Thực hành các thao tác quản lý phiên bản bằng Git,
quản lý mã nguồn trên GitHub và sử dụng Jira.
## Nội dung thực hành

1. Cài đặt và cấu hình Git.
2. Khởi tạo Repository.
3. Quản lý tệp bằng Git.
4. Theo dõi lịch sử thay đổi bằng commit.
## Các công cụ sử dụng

- Visual Studio Code: Soạn thảo và quản lý mã nguồn.
- Git: Quản lý phiên bản mã nguồn.
- GitHub: Lưu trữ và chia sẻ Repository trực tuyến.
- Jira: Quản lý công việc và tiến độ dự án.
## Kết quả thực hành

Đã hoàn thành các thao tác:
- Cài đặt và cấu hình Git.
- Khởi tạo Repository.
- Tạo và quản lý các tệp.
- Thực hiện các thao tác add, commit.
- Kiểm tra lịch sử thay đổi.
